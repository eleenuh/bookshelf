# Favourite passages

A passage saved here appears in the book's pop-up straight under the details (Finished, Pages…), above "Impressions".
Books without a passage simply don't show one.

- One plain text file per book, named by the book's Goodreads **Book Id**: `11429027.txt`.
  The Book Id is the number in the book's Goodreads address, e.g. `goodreads.com/book/show/11429027-bonds`.
- Paste the passage as normal text. Line breaks and blank lines are kept.
- Optional: end with a line starting with a dash to show where it's from, e.g. `— p. 42` or
  `— chapter 3`. It's shown as a small note under the passage.
- Saving a file here on GitHub updates the website within a minute or two. To see it on your own
  computer first, run `python scripts/update_books.py` and refresh.

Example, `excerpts/52357.txt`:

```
So. The Spear-Danes in days gone by
and the kings who ruled them had courage and greatness.
— p. 3
```
